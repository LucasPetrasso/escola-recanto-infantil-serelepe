# Recanto Infantil Serelepe

Site institucional desenvolvido para o **Recanto Infantil Serelepe**, com o objetivo de apresentar a escola, suas turmas, atividades extracurriculares e informações institucionais de maneira acolhedora, moderna e responsiva.

O projeto foi desenvolvido como uma aplicação **front-end**, utilizando HTML5, CSS3 e JavaScript, com foco em organização de código, responsividade e experiência do usuário.

## Sobre o projeto

O site busca representar a identidade do Recanto Infantil Serelepe através de uma interface visualmente agradável e voltada ao público infantil e às famílias.

A aplicação apresenta diferentes páginas e seções com informações sobre a escola, incluindo:

* Informações sobre a instituição
* Turmas e faixas etárias
* Atividades extracurriculares
* Formas de contato
* Elementos visuais e imagens da escola
* Layout adaptado para diferentes dispositivos

## Tecnologias utilizadas

* **HTML5** — Estrutura e semântica das páginas
* **CSS3** — Estilização, layouts, animações e responsividade
* **JavaScript** — Interatividade e manipulação de elementos da página
* **Git** — Controle de versão
* **GitHub** — Hospedagem do repositório
* **Vercel** — Deploy e hospedagem do projeto

## Organização do CSS

O CSS foi organizado de forma modular para facilitar a manutenção e evolução do projeto.

```text
css/
├── components/
│   ├── carrossel.css
│   ├── footer.css
│   ├── header.css
│   └── hero.css
│
├── base.css
├── layout.css
├── main.css
├── reset.css
├── responsive.css
└── variables.css
```

A divisão permite separar responsabilidades, como:

* **reset.css** — normalização dos estilos padrão do navegador
* **variables.css** — variáveis utilizadas na identidade visual
* **base.css** — estilos base da aplicação
* **layout.css** — estrutura e organização dos elementos
* **main.css** — estilos gerais
* **responsive.css** — adaptação para diferentes tamanhos de tela
* **components/** — estilos específicos de componentes reutilizáveis

## 📱 Responsividade

O site foi desenvolvido com foco em uma experiência consistente em diferentes dispositivos.

Foram utilizados **media queries** para adaptar o layout de acordo com o tamanho da tela, contemplando:

* Smartphones
* Tablets
* Notebooks
* Desktops

A navegação também possui um **menu hamburguer** para dispositivos menores, proporcionando uma experiência mais adequada em telas reduzidas.

## Principais funcionalidades

* Navegação entre diferentes páginas do site
* Menu responsivo
* Menu hamburguer para dispositivos móveis

* Seção Hero com conteúdo visual
* Animações e efeitos de hover
